# Pattern Dojo

A DSA prep platform that teaches by pattern. Each problem gets the idea in plain language first, a C++ solution
that is compiled and tested on every build, scale tests that make the intended complexity necessary, questions on
why it works, an interview mode that feels like a real round, and spaced re-solving so the patterns stick.

Live site: https://amitdu6ey.github.io/pattern-dojo/ (read-only; running code needs the local judge)

**Status:** under construction. A loop advances one item of [`ROADMAP.md`](ROADMAP.md) at a time, following
[`LOOP.md`](LOOP.md), and pushes after each run whose build and tests pass. Progress is in [`LOG.md`](LOG.md).

- [`LEARNING.md`](LEARNING.md): the learning strategy and how an interview round is simulated.
- [`RESEARCH.md`](RESEARCH.md): what other DSA resources do, and what we take from them.

Static site, no framework, free to host. Python 3.9 standard library and `g++` (C++17) are the only tools.
