# Pattern Dojo

A DSA prep platform that teaches by pattern. Each problem gets the idea in plain language first, an interactive
visual where it helps, a C++ solution that is compiled and tested on every build, and spaced review so the
patterns stick.

**Status:** under construction. A loop advances one item of [`ROADMAP.md`](ROADMAP.md) at a time, following
[`LOOP.md`](LOOP.md). Progress is in [`LOG.md`](LOG.md).

Static site, no framework, free to host. Python 3.9 standard library and `g++` (C++17) are the only tools.
